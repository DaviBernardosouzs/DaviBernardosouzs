# Como usar

1. Abra o repositório de perfil: https://github.com/DaviBernardosouzs/DaviBernardosouzs
2. Substitua o README.md pelo arquivo deste pacote.
3. Adicione a pasta assets/profile/ mantendo os nomes dos arquivos. Você pode manter outros arquivos que já existam em assets/.
4. Salve os arquivos na branch padrão do repositório. Os caminhos relativos passam a funcionar no perfil.

O banner tem animações discretas em SVG. Todos os elementos visuais estão no pacote, sem dependência de serviços de estatísticas ou geradores de badges. Não é necessário configurar GitHub Actions para este visual.

Se publicar somente o README.md, as imagens não vão aparecer: a pasta assets/profile/ faz parte do layout.

O conteúdo dos projetos foi conferido nos repositórios públicos em 15/11/2026. Os textos resumem o que está documentado e implementado, sem atribuir métricas de desempenho ou garantias de produção.
